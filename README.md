# 🪙 Bale Market Bot

یک ربات هوشمند بله برای مشاهده **قیمت لحظه‌ای طلا، سکه و ارز**، بررسی وضعیت بازار، دریافت تحلیل هوشمند با هوش مصنوعی، محاسبه قیمت طلا، تنظیم هشدار قیمت و مشاهده تاریخچه قیمت‌ها.

این پروژه با **Node.js** و **JavaScript** توسعه داده شده و برای دریافت اطلاعات بازار از BRSAPI و برای تحلیل هوشمند از OpenRouter استفاده می‌کند.

## 🤖 تحلیل هوشمند بازار

ربات با استفاده از داده‌های واقعی بازار، اطلاعاتی مانند:

- قیمت فعلی طلا
- قیمت سکه امامی
- قیمت دلار
- درصد تغییرات
- تاریخچه کوتاه‌مدت قیمت‌ها

را در اختیار مدل هوش مصنوعی قرار می‌دهد تا یک تحلیل کوتاه و کاربردی از وضعیت بازار ارائه شود.

تحلیل هوشمند صرفاً جنبه اطلاعاتی دارد و جایگزین مشاوره مالی یا سرمایه‌گذاری نیست.

داده‌های مورد استفاده شامل:

- سکه

است.

مدل پیش‌فرض پروژه:


## 🔐 تنظیم متغیرهای محیطی

فایل `.env.example` را به `.env` تبدیل کرده و مقادیر موردنظر را وارد کنید:

```env
BALE_BOT_TOKEN=
BRS_API_KEY=
OPENROUTER_API_KEY=
OPENROUTER_MODEL=openrouter/free
```

### BALE_BOT_TOKEN

توکن ربات بله که از BotFather دریافت می‌شود.

### BRS_API_KEY

کلید API سرویس BRSAPI برای دریافت اطلاعات بازار.

### OPENROUTER_API_KEY

کلید API سرویس OpenRouter برای فعال‌سازی تحلیل هوشمند.

### OPENROUTER_MODEL

مدل مورد استفاده برای تحلیل هوشمند.

مقدار پیش‌فرض:

```env
OPENROUTER_MODEL=openrouter/free
```

## 🔄 مانیتور بازار

ربات به‌صورت خودکار اطلاعات بازار را دریافت می‌کند و:

1. اطلاعات جدید بازار را دریافت می‌کند.
2. قیمت‌های منتخب را در تاریخچه ذخیره می‌کند.
3. هشدارهای فعال را بررسی می‌کند.
4. در صورت رسیدن قیمت به مقدار تعیین‌شده، پیام هشدار ارسال می‌کند.

فاصله بروزرسانی پیش‌فرض:

```text
60 seconds
```

## 💾 ذخیره‌سازی

در نسخه فعلی، برای سادگی و اجرای آسان پروژه از فایل‌های JSON استفاده شده است.

### history.json

برای ذخیره تاریخچه قیمت‌های:

- طلای ۱۸ عیار
- سکه امامی
- دلار

### alerts.json

برای ذخیره هشدارهای کاربران و شرایط فعال شدن آن‌ها.

این ساختار برای پروژه‌های کوچک و نمونه‌های اولیه مناسب است و در نسخه‌های آینده می‌توان آن را با MongoDB یا PostgreSQL جایگزین کرد.

## 🔔 سیستم هشدار قیمت

کاربر می‌تواند برای دارایی‌های منتخب یک قیمت هدف تعیین کند.

برای مثال:

```text
طلای ۱۸ عیار
قیمت فعلی: 7,000,000

قیمت هدف: 7,500,000
شرط: رسیدن قیمت به بالاتر از مقدار تعیین‌شده
```

ربات بازار را به‌صورت دوره‌ای بررسی می‌کند و پس از فعال شدن شرط، هشدار را برای کاربر ارسال می‌کند.

پس از ارسال موفق هشدار، هشدار از لیست فعال حذف می‌شود.

---

## 🧮 محاسبه قیمت طلا

کاربر می‌تواند وزن طلا و عیار موردنظر را وارد کند.

ربات با استفاده از قیمت لحظه‌ای دریافت‌شده از API، ارزش تقریبی طلای واردشده را محاسبه می‌کند.

فرآیند کلی:

```text
وزن طلا
    ↓
انتخاب عیار
    ↓
دریافت قیمت لحظه‌ای
    ↓
محاسبه
    ↓
نمایش نتیجه
```
